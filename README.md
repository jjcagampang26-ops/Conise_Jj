# Conise_Jj
IPT FINAL PROJECT
Project Title: VetAppoint: Veterinary Appointment Management System
Student Name: Janiesha Justine C. Conise

Website Category: Booking / Reservation / Appointment

Project Description: VetAppoint is a web-based appointment system for a veterinary clinic that handles grooming, check-up, and vaccination bookings for dogs and cats. It replaces manual scheduling with an online booking process and gives clinic staff one place to manage requests. The system has two interfaces. The first is a public page for pet owners, which needs no login. The second is an admin dashboard where staff accept or reject appointments, track patients, and schedule vaccinations. The system works on its own without a database, and it can also be connected to a SQL Server (SSMS) database for permanent storage.

Main features: On the owner side, a visitor opens the home page, clicks “Book an Appointment,” and fills out a two-step form for the owner and pet details. The form checks every entry before it can be submitted. Names, breed, and color accept letters only and are capitalized automatically. Phone number, age, and weight accept numbers only and have set length limits. The phone number must be exactly 11 digits. The email must contain “@” and a valid domain, and common domain typos such as “gmai.com” are rejected. The time dropdown offers only the clinic’s operating hours, from 9:00 AM to 10:00 PM, in AM/PM format. A notification bell lets owners enter their email to see upcoming vaccination reminders. The home page also shows the clinic’s services and contact details.

On the admin side, the dashboard shows the total animals, today’s appointments, cancellations, completed patients, and upcoming vaccinations. The dashboard updates automatically, so new bookings appear without refreshing the page. The Appointments tab lets the admin accept or reject each request, and accepted ones move to Patient Records. In Patient Records, the admin can mark a patient as done or cancelled, or delete the record. The record shows the pet’s details, appointment type, and the owner’s email and phone number. The Patient Summary keeps the full history of completed and cancelled appointments, with the date and time of each action. In the Vaccination tab, the admin picks a pet, sees the original date the owner booked, chooses a vaccine suited to the pet’s species, and sets the next schedule. This notifies the owner and places the pet in either the dog or the cat vaccination list.

Technologies Used: The website is built with HTML for structure, CSS for the minimalist white-and-blue design, and JavaScript for all functionality. The JavaScript uses arrays, loops, switch-case statements, object-oriented programming with classes, inheritance, and polymorphism, DOM manipulation, and asynchronous programming with async/await. Data is stored in the browser’s localStorage so the system runs without a server. For database storage, the project includes a Microsoft SQL Server (SSMS) schema and an optional Node.js and Express API that uses the mssql package to connect the website to the database.
